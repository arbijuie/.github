# Arbijuie

Arbijuie builds infrastructure for systematic funding-rate arbitrage.

## Public Access Right Now

The only public repository at the moment is:

- [frontend](https://github.com/arbijuie/frontend) - Public interface and operator-facing product surface.

The core trading and research repositories are currently private while we harden reliability and risk controls for broader publication.

## What You Can Explore Today

- Frontend architecture and UX direction
- Product progress through commits and releases
- Open issues and enhancement requests in the frontend repository

## Current Priorities

- Operational reliability
- Risk-first execution controls
- Clean release discipline for future open components

## Collaboration

If you want to collaborate, open an issue in [frontend](https://github.com/arbijuie/frontend/issues) with your proposal, use case, or integration idea.
