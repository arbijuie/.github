# Arbijuie

We build practical infrastructure for funding-rate arbitrage research and operations.

## Core Projects

- [arbitrage](https://github.com/arbijuie/arbitrage) - Data ingestion, scoring, API, and operations workflows.
- [frontend](https://github.com/arbijuie/frontend) - Standalone interface for visibility and operator workflows.

## Focus

- Reliable multi-exchange market data
- Risk-aware opportunity ranking
- Transparent release and operations discipline
